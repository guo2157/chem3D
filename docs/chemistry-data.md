# 化学数据记录

## BCC α-Fe

- 结构：体心立方。
- 位点：`(0,0,0)` 与 `(1/2,1/2,1/2)`。
- 晶格参数：`a = 2.866 Å`（室温常见教学值）。
- Z：2。
- 配位数：8。
- 数据来源：*Lattice Parameter of Alpha Iron by Divergent Beam Diffraction*，DOI `10.1063/1.1708081`。
- 状态：已验证教学模型；正式发布前仍建议由化学教师复核讲解文字。

## SC Po 与 FCC Cu

当前用于验证统一数据架构、粒子计数和渲染扩展。界面明确标记为“实验模型”，晶格参数与教学表述尚未完成两个独立来源的复核，不进入默认教学方案。

## 计算边界

- 晶胞粒子数来自唯一位点占有率之和，不从渲染副本反推。
- 视觉球半径不参与密度、距离或配位计算。
- 理论密度使用 `ρ = ZM/(NₐV)`，其中 `1 Å³ = 10⁻²⁴ cm³`。
