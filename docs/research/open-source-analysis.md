# 开源参考分析

本项目没有复制下列项目的代码或数据，只参考公开功能思路。

## Unit Cell Generator

- 可借鉴：教材式投影、边界副本、六棱柱展示单元、重叠原子消歧。
- 许可证：未声明，默认保留所有权利。
- 决策：禁止代码与数据复用，只独立实现交互和数学原理。

## UnitCellVisualizer

- 可借鉴：分层堆叠、透明检视、配位数视图和教学评估思路。
- 许可证：GPL-2.0。
- 决策：不复制实现，避免项目整体受 GPL 约束。

## crysviz

- 可借鉴：轻量浏览器渲染、测量、晶向视角与角落坐标轴。
- 许可证：AGPL-3.0。
- 决策：禁止代码复用，功能独立设计。

## cifvis

- 可借鉴：标签防碰撞、触控和 Web Component 封装思路。
- 许可证：MPL-2.0。
- 决策：当前版本不复用其文件；未来如需复用必须单独登记并履行文件级开源义务。

## 当前独立实现

- 位点只存储 `[0,1)` 内唯一坐标，边界副本由 `generateRenderedAtoms` 生成。
- 粒子计数按唯一位点占有率求和，不从渲染对象反推。
- 相机、拾取、扩展、位置着色和教学步骤均从产品规范独立实现。
