# 前端设计实现说明

设计源以 `first-final.md` 第九部分为准，并由 `design-system/chem3d/MASTER.md` 固化。

## 采用的方向

- 科学仪器工作台，而非营销落地页或儿童化拟物界面。
- 默认浅色，深青只表达交互状态，元素色保留给 3D 场景。
- 系统中文字体栈，零运行时字体下载。
- 3D 画布为唯一强视觉，面板使用克制边界与少量阴影。
- 桌面三栏、平板抽屉、手机画布加下方工具区、课堂全屏控制。

## 可访问性

- 所有按钮使用原生语义，并提供可见焦点环。
- 切换按钮公开 `aria-pressed` 状态。
- 画布有中文操作摘要和 `aria-live` 选择播报。
- 支持 `prefers-reduced-motion`。
- 颜色之外同时使用标签、贡献值和线型表达信息。

## 自动设计建议的取舍

UI 检索曾返回深色橙色拟物风格、Nunito/DM Sans 与单列落地页结构。以上建议与课堂投影、离线字体、化学元素色语义及多面板工具定位冲突，因此全部舍弃；只保留可见焦点、响应式触控目标和减少动态效果等通用原则。
