# 化学空间3D

面向中国高中化学课堂的 3D 晶体结构教学平台。当前版本完成了 M1 项目骨架，并实现了可交互的 BCC（体心立方）教学纵向切片。

## 已实现

- React 18、TypeScript strict、Vite、Zustand、Three.js 原生渲染。
- SC、BCC、FCC 三种立方晶胞数据；BCC 为默认教学模型。
- 旋转、缩放、平移、点击选原子、重置与晶向视角。
- 球棍、堆积、骨架；按元素/按位置着色；1×1×1 至 3×3×3 扩展。
- 晶胞截断、体对角线、粒子数、体积与理论密度。
- 探索、教学、课堂演示三种模式与 BCC 八步教学方案。
- 浅色、深色、高对比度、键盘快捷键和移动端布局。
- WebGL 2 检测、减少动态效果支持、URL 状态摘要。

## 本地运行

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm run build
npm test
```

所有依赖均本地打包，不使用运行时 CDN 或 Google Fonts。

## 快捷键

- `R` / `0`：教材视角
- `1` / `2` / `3`：沿 a / b / c 轴观察
- `L`：标签
- `C`：截断显示
- `F`：全屏
- `←` / `→`：教学模式上一步 / 下一步

## 数据说明

BCC α-Fe 使用常见室温教学晶格参数 `a = 2.866 Å`，来源记录见 `docs/chemistry-data.md`。SC Po 与 FCC Cu 当前标记为实验模型，正式进入教学模式前仍需完成双源复核。
